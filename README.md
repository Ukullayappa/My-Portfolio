# Uravakonda Kullayappa Portfolio

Professional Full Stack Developer Portfolio built using React.js, Node.js, Express.js and PostgreSQL.

## Live Demo
https://my-portfolio-pi-eight-18.vercel.app

## Features
- Responsive Design
- Project Showcase
- Contact Form
- Resume Download
- Smooth Animations
- Mobile Friendly UI

## Tech Stack
**Frontend:**
- React.js
- Bootstrap 5
- Framer Motion

**Backend:**
- Node.js
- Express.js

**Database:**
- PostgreSQL

## Installation
git clone https://github.com/Ukullayappa/My-Portfolio

npm install
npm run dev
